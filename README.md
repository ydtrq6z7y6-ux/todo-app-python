# To-Do App (Python CLI)

## Overview

This is a simple command-line To-Do application built in Python. It allows users to manage daily tasks by adding, viewing, and deleting items.

## Features

* Add new tasks
* View all tasks
* Delete tasks
* Data is saved using JSON file

## Technologies

* Python
* JSON (file storage)

## How to run

python todo.py
